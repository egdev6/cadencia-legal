Cadencia

Home · Privacy Policy

Cadencia is a private, locally operated tool for scheduling and publishing social media content. It is currently in testing and is not a hosted public service: there is no public registration. This static website has no forms or application sign-up; hosting metadata is described under “This website” below.

Operator and contact

Each Cadencia installation is operated by its local operator. For this site, the operator is the GitHub user @egdev6, which is the only published contact channel. No email address or postal address is published.

When contacting, please do not include passwords, access tokens, or other private content in public GitHub posts. Do not post account credentials publicly under any circumstances.

Data a Cadencia installation stores

Cadencia runs locally. Data is stored on the machine where the installation runs, not on servers operated through this website. Depending on configuration, a local installation may store:

  • Profile identifiers of the connected provider accounts (for example account IDs or handles).
  • OAuth access and refresh tokens used to call provider APIs.
  • Content prepared for publishing: videos, images, and captions.
  • Scheduling data, application settings, and preferences.
  • Operational logs.
  • Backups, if backups are configured.

Security

When a master key is configured, secrets such as OAuth tokens are encrypted at rest. This does not mean that every stored file or browser session is encrypted, and no statement on this page should be read as a guarantee that it is.

How data is shared

To carry out the actions a user requests, Cadencia sends data to third parties:

  • Provider APIs. Authorization credentials and the content the user chooses to publish (for example videos, images, and captions) are sent to the relevant provider, such as TikTok, Google, LinkedIn, or X, so the requested action can be performed.
  • Optional agent and model providers. When optional browser-agent or model-based features are enabled, content or instructions may be processed by the browser agent or model providers those features use.

These third parties process data under their own terms and privacy policies, which are linked below. No claim is made here about the exact scope of their processing.

This website

This website is a set of static pages. It adds no cookies, no analytics, no scripts, no advertising, no tracking, and it does not sell data. The site is hosted on GitHub Pages: GitHub may process request metadata (such as IP address and request logs) when pages are served, under GitHub's own privacy terms.

Retention

There is no fixed retention period. Locally stored data is kept until the local operator deletes the records, files, or backups. Data held by a provider remains subject to that provider until it is deleted there or the provider's own retention rules apply.

Disconnecting, revoking, and deleting

These actions are different, and it matters which one is used:

  • Disconnecting an account or revoking authorization stops Cadencia from performing new actions with that account. It does not delete content that was already published on the provider.
  • Deleting a scheduled post locally removes it from the local installation, but does not necessarily cancel a schedule that was already created on the provider. The final state should be verified on the provider.
  • Remote posts must be deleted on the provider platform itself; deleting local records does not remove them.
  • Backups may continue to contain data after the original record is deleted, until the backup itself is deleted or overwritten.

Your controls

  • Revoke an application's authorization for an account through that provider's own settings, such as the connected-apps or security page of the account (see the Google permission-management link below).
  • Delete local records, files, and backups directly on the machine where the Cadencia installation runs.
  • Ask the operator about data handled by a Cadencia installation via the GitHub profile @egdev6 (see the contact cautions above).
