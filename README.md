# cadencia-legal

Static legal-information site for **Cadencia**, a private, locally operated
social publishing tool currently in testing. The Cadencia application source
lives in a separate private repository; this repository hosts only the public
legal pages and is served by GitHub Pages from `/docs` on `main`.

## Published URLs

- Homepage: https://egdev6.github.io/cadencia-legal/
- Privacy: https://egdev6.github.io/cadencia-legal/privacy/
- Terms: https://egdev6.github.io/cadencia-legal/terms/

## Contact

GitHub profile [@egdev6](https://github.com/egdev6) — the only published
contact channel. No email address is published.

## Notes

- Pages are plain HTML with a single local stylesheet; no scripts, trackers,
  cookies, or external assets.
- Nothing outside `docs/` is served by GitHub Pages (`/docs` source, with
  `.nojekyll`).
